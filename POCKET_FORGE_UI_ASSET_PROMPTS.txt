POCKET FORGE UI ASSET IMAGE GENERATION PROMPTS
================================================

목적
----

승인된 보랏빛 캐주얼 Pocket Forge 메인 화면 가스샷을 기준으로
UI 요소를 하나씩 독립 이미지로 생성하기 위한 통합 프롬프트 문서다.

각 이미지는 기능을 식별할 수 있는 형태와 아이콘만 포함한다.
레벨, 가격, 재화량, 진행도, 챕터명처럼 변경되거나 번역되는 정보는
이미지에 굽지 않고 Unity의 TextMeshPro와 런타임 데이터로 표시한다.


1. 제작 원칙
-------------

1. 하나의 생성 요청에서는 정확히 한 개의 UI 요소만 생성한다.
2. 생성 이미지에는 글자, 숫자, 단어, 약어, 재화 기호를 넣지 않는다.
3. 반드시 플레이어가 알아야 하는 정보도 이미지에 굽지 않는다.
   Unity TextMeshPro 또는 별도 런타임 UI 레이어로 표시한다.
4. 버튼의 기능은 가능한 한 곡괭이, 깨진 광석, 상자, 플라스크 같은
   아이콘과 버튼의 색·형태만으로 구분한다.
5. 번역되거나 수치가 변하는 모든 정보가 들어갈 공간은 비워 둔다.
6. 패널, 버튼, 카드, 아이콘은 각각 별도 이미지로 만든다.
7. 생성 결과는 #00FF00 단색 크로마키 배경에서 추출해 투명 PNG로 변환한다.
8. 크로마키 제거를 위해 실제 UI 요소에는 녹색을 사용하지 않는다.
9. 승인된 캐주얼 가스샷은 스타일 참고용이며 화면 전체를 복제하지 않는다.
10. 무거운 금속, 사실적인 오염, 두꺼운 검정 테두리, 과도한 금장,
    해골, 위협적인 RPG 분위기는 사용하지 않는다.

- 미션: 체크 표시가 있는 클립보드
- 상점: 보석이 담긴 카트
- 설정: 톱니바퀴

사용자 접근성을 위해 버튼 명칭이 필요해지면 이미지를 다시 만들지 않고
Unity의 현지화 TextMeshPro 레이어를 선택적으로 표시한다.

6. 생성 결과 검수 기준
----------------------

- 한 이미지에 정확히 한 요소만 있는가
- 글자, 숫자, 가짜 문자, 장식 문자가 없는가
- UI 요소 내부에 Unity 텍스트를 배치할 빈 공간이 충분한가
- 이미지의 모든 외곽이 잘리지 않았는가
- 정면 시점이며 원근 왜곡이 없는가
- #00FF00 배경이 완전히 균일한가
- 실제 UI 요소 안에 녹색이 없는가
- 크로마키 제거 후 외곽에 녹색 테두리가 남지 않는가
- 보랏빛 캐주얼 가스샷과 테두리·재질·조명이 일치하는가
- 무거운 금속, 두꺼운 검정 테두리, 과한 금장, 해골이 없는가
- 아이콘이 작은 모바일 화면에서도 형태만으로 구분되는가
- 패널과 버튼이 Unity 9-slice 또는 Simple 이미지로 사용 가능한가
- 변경되는 정보가 이미지에 고정되어 있지 않은가


7. Unity 적용 메모
------------------

- 패널과 버튼의 글자·수치는 TextMeshPro로 분리한다.
- 재화 아이콘과 수량도 서로 다른 GameObject로 구성한다.
- 진행 바는 Frame, Track, Fill을 분리한다.
- Fill은 가능하면 Unity Image의 Filled 또는 폭 조절 방식으로 구현한다.
- 버튼 배경과 기능 아이콘을 분리해 눌림·비활성·잠금 상태에 재사용한다.
- 알림 배지, 잠금 아이콘, 추천 별은 독립 Overlay 이미지로 사용한다.
- 패널 가장자리가 늘어나는 자산은 9-slice 경계를 직접 검수한다.
- 그림 자체의 비율을 보존해야 하는 아이콘은 정사각형 투명 캔버스에 배치한다.
- 모든 생성 원본은 투명 PNG 변환본과 구분해 보관한다.
