POCKET FORGE — 장비·박물관·업적 UI 요소별 이미지 생성 프롬프트
=================================================================

문서 목적
---------

승인된 장비·박물관·업적 가스샷을 실제 Unity UI 자산으로 분해하기 위한 통합 프롬프트 문서다.
각 결과물은 가스샷의 색, 외곽 형태, 비율, 테두리, 광택, 그림자를 최대한 그대로 유지해야 한다.
이 문서에서 말하는 "유사"는 같은 분위기의 재디자인이 아니라 승인 가스샷에 다시 겹쳤을 때
원래 요소를 거의 덮을 수 있는 수준의 재현을 뜻한다.

단, 이미지 생성만으로 픽셀 단위 100% 동일성을 보장할 수는 없다.
따라서 아래의 A 방식인 "원본 크롭 제한 편집"을 항상 먼저 사용하고,
원본에서 분리할 수 없는 요소에만 B 방식인 "참조 기반 재생성"을 사용한다.

2. 절대 규칙
-------------

1. 한 번의 생성 또는 편집 요청에는 정확히 하나의 UI 요소만 넣는다.
2. 승인 가스샷을 "스타일 참고"가 아니라 형태·재질·색상의 절대 기준으로 사용한다.
3. 원본에서 대상 요소를 24~48px의 안전 여백과 함께 잘라 편집 입력 이미지로 사용한다.
4. 대상 요소의 외곽 실루엣, 가로세로 비율, 모서리 곡률, 테두리 두께, 그라데이션,
   하이라이트 위치, 내부 그림자, 외부 그림자를 임의로 바꾸지 않는다.
5. 화면 전체를 다시 그리지 않는다. 주변 카드, 배경, 다른 아이콘을 결과에 넣지 않는다.
6. 실제 자산에는 글자, 숫자, 가격, 수량, 레벨, 퍼센트, 진행도, 보상 수치,
   화폐 기호, 한글, 영문, 가짜 글자, 읽을 수 없는 장식 문자를 넣지 않는다.
7. 제목·설명·수치가 있던 영역은 깨끗하고 균일한 빈 표면으로 복원한다.
8. X, 체크, 잠금, 화살표, 트로피처럼 기능을 형태만으로 알아야 하는 고정 아이콘은 허용한다.
9. 텍스트와 동적 수치는 Unity TextMeshPro와 런타임 데이터로 올린다.
10. 반복 카드의 기본 표면은 하나만 만든다. 선택, 희귀도, 장착, 완료, 잠금은 별도 오버레이로 만든다.
11. 정면 직교 시점만 사용한다. 원근, 기울임, 회전된 UI 판, 사선 카메라는 금지한다.
12. 자산의 모든 끝과 광택이 캔버스 안에 들어와야 한다. 잘림과 과도한 외곽 발광은 금지한다.
13. 화면 적용용 패널과 카드는 좌우 대칭과 9-slice 가능한 중앙 영역을 유지한다.
14. 원본에 없는 나사, 보석, 금속 장식, 리본, 날개, 입자, 문양을 추가하지 않는다.
15. 탕탕특공대 또는 다른 게임의 고유 아이콘과 레이아웃을 복제하지 않는다.


3. 출력 배경과 투명화 규칙
--------------------------

생성 도구가 직접 투명 PNG를 안정적으로 만들 수 있으면 투명 배경을 사용한다.
그렇지 않으면 아래 키 컬러 중 대상 자산에 들어 있지 않은 색을 하나만 선택한다.

- 기본 키: 완전한 #00FF00. 녹색 완료 표시나 녹색 보너스가 없는 자산에 사용한다.
- 녹색 자산용 키: 완전한 #FF00FF. 단, 자산에 자홍·보라 외곽광이 있으면 사용하지 않는다.
- 녹색과 보라가 함께 있는 자산용 키: 완전한 #FF0000. 빨간 알림 배지에는 사용하지 않는다.

키 배경은 단색이어야 하며 그라데이션, 조명, 바닥, 반사, 그림자, 텍스처가 없어야 한다.
배경색은 자산 내부에 절대 쓰지 않는다. 투명화 후 1px 가장자리에 키 컬러가 남지 않도록 despill한다.

선 굵기나 형태가 실제로 다를 때만 해당 화면 크롭을 입력으로 하여 제한 편집한다.

13. 가스샷 근접도 검수 — 반드시 수행
-----------------------------------

1. 승인 가스샷과 동일한 1440×3088 빈 캔버스를 만든다.
2. 분리된 자산을 원래 위치와 원래 표시 크기에 배치한다.
3. 승인 가스샷을 그 위에 50% 투명도로 겹친다.
4. Difference 또는 깜빡임 비교로 외곽선과 중심축을 확인한다.
5. 아래 오차를 넘으면 승인하지 않고 다시 크롭 편집한다.

- 큰 모달·타이틀: 외곽 기준 4px 초과 차이 금지
- 카드·행·버튼: 외곽 기준 3px 초과 차이 금지
- 작은 배지·아이콘: 표시 크기의 3% 초과 차이 금지
- 반복 카드: 같은 계열끼리 너비·높이·곡률 100% 동일
- 열 정렬: 아이콘·텍스트·진행·보상·상태 열의 중심축 흔들림 금지

"분위기가 비슷하다" 또는 "눈으로 보기에는 괜찮다"는 통과 기준이 아니다.
원본 외곽을 실제로 덮을 수 있고, 글자가 제거된 빈 영역이 깨끗해야 통과한다.


14. Unity 임포트 메모
--------------------

- 패널·카드·버튼: Sprite (2D and UI), Image.Type.Simple을 기본으로 사용한다.
- 실제로 늘려야 하는 공용 표면만 투명 여백을 정리한 뒤 9-slice border를 설정한다.
- 진행 채움: Image.Type.Filled, Horizontal, Origin Left.
- 아이콘: Preserve Aspect 활성화.
- 배지·오버레이: 기본 카드의 자식으로 두고 카드 밖 발광이 잘리지 않도록 마스크 사용을 검토한다.
- TMP 텍스트와 수치는 이미지보다 위 레이어에 놓고 Auto Size에만 의존하지 않는다.
- 1440×3088 가스샷 비율 외에도 16:9, 19.5:9, 20:9 Safe Area에서 겹침과 잘림을 재검수한다.
- 실제 RectTransform 배치는 `POCKET_FORGE_MAIN_UI_LAYOUT_CORRECTION_PROMPT.txt`와
  `pocket-forge-ui-layout-guard`의 비겹침·앵커 규칙을 함께 적용한다.
