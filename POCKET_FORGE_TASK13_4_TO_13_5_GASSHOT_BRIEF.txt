2. 공통 시각 방향

- 장르: 밝고 중독성 있는 캐주얼 방치형 광산 게임

- 기본 팔레트: 짙은 네이비·보라 패널, 라벤더 테두리, 청록 정보색,
  오렌지 주요 버튼, 녹색 보너스·완료 상태
- 정보 위계: 화면 제목 > 요약 수치 > 핵심 카드/목록 > 주요 행동 > 닫기
- 패널과 행 사이 간격, 아이콘 전용 영역, 텍스트 안전 영역을 명확히 분리한다.
- 버튼은 누를 수 있다는 것이 즉시 보여야 하며, 비활성·진행 중·수령 가능·완료 상태가
  색과 아이콘만으로도 구분되어야 한다.
- 기존 V5 HUD와 같은 세계관을 유지하되 테두리 중첩과 과도한 광택은 줄인다.
- 다른 게임의 로고·고유 캐릭터·고유 UI를 복제하지 않는다.


3. Task 13-4 장비 화면

반드시 유지할 기능
- 곡괭이, 드릴, 로봇, 부적의 4개 장비 슬롯
- Common/Rare/Epic/Legendary 등급과 장비 채굴력 보너스
- 장착 중인 장비와 인벤토리 장비 구분
- 선택 장비와 현재 장비의 성능 비교
- 장착, 해제, 동일 장비 3개 합성, 자동 장착
- 페이지당 장비 6개와 페이지 이동

권장 화면 구조
- 상단: "장비" 타이틀과 전체 장비 채굴력 요약
- 타이틀 아래: 4개 장비 슬롯 카드. 아이콘, 슬롯명, 등급, 보너스를 한눈에 표시
- 중앙: 장비 인벤토리 목록. 각 행에 아이콘 / 이름 / 등급 / 보너스 / 장착 상태 표시
- 하단: 선택 장비 상세 비교와 행동 버튼 영역
- 가장 아래: 닫기 버튼. 행동 버튼과 겹치지 않는 독립 안전 여백 확보

현재 화면에서 반드시 개선할 부분
- 하단 선택 장비 정보와 행동 버튼이 서로 겹치는 문제 제거
- 목록 아이콘과 장비 이름 사이 여백 확대
- 선택된 행, 장착 중인 행, 합성 가능한 행을 서로 다른 상태로 표현
- 등급별 색과 작은 배지 또는 별 표현을 일관되게 적용
- 주요 행동 한 개를 가장 강하게, 보조 행동은 한 단계 낮게 표현
- 작은 화면에서도 4슬롯과 6개 목록의 텍스트가 눌리지 않게 높이 재배분


4. Task 13-5A 박물관 화면

반드시 유지할 기능
- 박물관 / 업적 2개 탭
- 전체 광물 도감 채굴력 보너스 요약
- Copper, Iron, Gold, Crystal 4종의 발견 상태와 누적 채굴 수
- 광물별 보너스와 미발견 상태
- 향후 광물 종류가 늘어날 수 있는 스크롤 가능한 구조

권장 화면 구조
- 상단: "수집 기록" 타이틀
- 그 아래: 박물관/업적 탭과 전체 도감 보너스 카드
- 중앙: 광물 카드 4개. 아이콘 전용 칸 / 광물명·진행 / 보너스 칸으로 3분할
- 미발견 광물은 실루엣, 잠금 표시, 다음 발견 힌트로 표현
- 각 광물은 다음 보너스 단계까지의 작은 진행 바 또는 마일스톤을 제공
- 하단: 닫기 버튼

현재 화면에서 반드시 개선할 부분
- 광석 아이콘이 광물명과 누적 수 텍스트를 침범하는 문제 제거
- Copper/Iron/Gold/Crystal을 서로 다른 전용 아이콘과 색으로 구분
- 발견 완료, 다음 단계 진행 중, 미발견 상태의 대비 강화
- 넓은 빈 공간을 줄이고 카드 높이와 하단 여백을 균형 있게 재배치


5. Task 13-5A 업적 화면

반드시 유지할 기능
- 광석 채굴, 챕터 정복, 시설 강화, 광부 성장, 연구 진행, 장비 수집의 6종 업적
- 업적별 현재 진행도와 단계 목표
- Credits, Gem, 설계도 코어 보상
- 수령 가능, 진행 중, 완료 상태와 중복 수령 방지
- 향후 업적 수가 늘어날 수 있는 스크롤 가능한 구조

권장 화면 구조
- 박물관 화면과 동일한 타이틀·탭 틀을 사용해 한 세트처럼 보이게 한다.
- 상단에 수령 가능한 업적 수를 작고 선명한 알림 배지로 표시한다.
- 각 행은 업적 전용 아이콘 / 이름·진행 바 / 보상 / 상태 버튼 순서로 구성한다.
- 수령 가능 버튼은 오렌지 또는 밝은 녹색, 진행 중은 낮은 채도,
  완료는 체크 표시와 짧은 완료 라벨로 구분한다.
- 하단: 닫기 버튼

현재 화면에서 반드시 개선할 부분
- 여섯 행이 같은 형태로 반복되어 단조로운 문제를 업적별 아이콘과 진행 바로 보완
- 보상 아이콘과 수치를 한 묶음으로 만들어 목표 정보와 구분
- 수령 가능 버튼의 우선순위를 강화하고 진행 중 버튼은 시각적으로 후퇴
- 긴 번역 문구와 큰 숫자가 들어가도 버튼과 겹치지 않는 안전 폭 확보


6. 최종 자산 분리 시 이미지에 굽지 않을 정보

- 장비명, 광물명, 업적명, 버튼 문구, 탭 문구, 완료·진행 상태 문구
- 레벨, 등급명, 보너스 %, 채굴 수, 진행도, 비교 수치
- Credits, Gem, 설계도 코어 수량과 보상 수량
- 수령 가능한 업적 수, 페이지 번호, 잠금 조건
- 한국어·영어·일본어·중국어로 번역되는 모든 문자열

위 정보는 Unity TextMeshPro와 런타임 데이터로 표시한다.
최종 분리 자산은 글자 없는 패널, 버튼 표면, 탭 표면, 카드, 진행 바,
상태 배지, 장비·광물·업적 아이콘으로 제작한다.
일반 이미지의 Unity Image Type은 Simple을 우선 사용하고,
실시간으로 길이가 변해야 하는 진행 바 Fill만 Filled를 허용한다.


7. 가스샷 생성용 통합 요청문

Pocket Forge라는 캐주얼 방치형 광산 모바일 게임의 완성형 UI 가스샷 3장을
하나의 일관된 디자인 시스템으로 제작한다. 기준 화면은 세로 1440×3088이며
Android Safe Area와 상단 펀치홀을 고려한다. 배경에는 보라색·청록색 수정 광산과
기존 메인 HUD를 어둡게 유지하고, 그 위에 중앙 모달을 표시한다.

화면 A는 장비 화면이다. 상단에 장비 제목과 전체 채굴력 보너스, 그 아래에
곡괭이·드릴·로봇·부적 4개 슬롯, 중앙에 6개 장비 인벤토리 행,
하단에 선택 장비 비교와 장착/해제/3개 합성/자동 장착 행동 영역을 배치한다.

화면 B는 광물 박물관이다. 수집 기록 제목, 박물관/업적 탭, 전체 도감 보너스,
Copper/Iron/Gold/Crystal 4종의 서로 다른 광물 아이콘, 발견 상태, 누적 진행,
개별 보너스와 다음 마일스톤을 보여준다.

화면 C는 업적이다. 같은 수집 기록 모달과 탭 구조 안에 광석 채굴, 챕터 정복,
시설 강화, 광부 성장, 연구 진행, 장비 수집 6개 업적을 배치하고,
각 행에 전용 아이콘, 진행 바, 보상, 수령 가능/진행 중/완료 상태를 표시한다.

시각 스타일은 친근한 3D 장난감 질감의 프리미엄 캐주얼 모바일 게임 UI다.
짙은 네이비·보라 패널, 라벤더 림, 청록 정보색, 오렌지 주요 버튼,
녹색 긍정 상태를 사용한다. 둥글고 두툼하지만 과도하게 번쩍이지 않으며,
아이콘과 텍스트가 절대 겹치지 않고 모든 카드와 버튼에 충분한 안전 여백을 둔다.
기존 스크린샷의 기능과 정보 위계만 유지하고 현재의 겹침·압축·빈 공간 문제는
완전히 재설계한다. 가짜 문자나 깨진 글자를 만들지 말고, 정확한 문구 생성이
어려우면 텍스트가 들어갈 깨끗한 빈 영역으로 남긴다. 로고나 워터마크는 넣지 않는다.


8. 가스샷 승인 후 실제 적용 순서

1) 승인된 완성 스냅샷을 기준으로 공통 규격과 픽셀 비율 확정
2) 글자 없는 UI 표면과 아이콘을 요소별로 한 장씩 생성
3) 투명 배경·알파 가장자리·색 번짐·문자 혼입 검수
4) Unity에 Simple 중심으로 임포트하고 기존 런타임 데이터 재연결
5) 1440×3088 Simulator 비교 캡처로 위치·비율·Safe Area 검수
6) 사용자 화면 승인 후 APK·실기기 검증
